# Conventions — OnlyGlamps

## URL

- Все публичные URL на латинице, нижний регистр, дефис как разделитель.
- Один объект = один URL: `/{region}/{city}/{slug}-{id}/`
- Город/район не существует без региона.
- `/page/1/` не существует. Первая страница = базовый URL.
- Trailing slash обязателен для всех страниц.
- Старые/неканонические URL → 301 на основной.

## SEO

### Индексируемые (index, follow)
- Главная `/`
- Регионы `/{region}/`
- Города `/{region}/{city}/`
- Типы `/{region}/{type}/`
- Регион+город+тип `/{region}/{city}/{type}/`
- Карточки `/{region}/{city}/{slug}-{id}/`

### Не индексируемые (noindex, follow)
- Страницы с GET-параметрами (фильтры, сортировки, даты)
- Пагинация `/page/2/`, `/page/3/`
- Пустая выдача
- `/search/`
- Служебные страницы

### Canonical
- Каждая индексируемая страница имеет `<link rel="canonical">`.
- Canonical всегда ведёт на чистый URL без GET-параметров.

### Title и H1
- Title и H1 должны быть разными.
- Оба содержат город/район и тип объекта.
- Не допускается шаблонная одинаковость.

## API

### Формат ответов

Успех:
```json
{ "data": [...], "total": 42, "page": 1, "pageSize": 20 }
```

Ошибка:
```json
{ "error": "Not found", "code": "OBJECT_NOT_FOUND" }
```

### Пагинация
- Query: `?page=1&pageSize=20`
- Default pageSize: 20, max: 100.

### Именование
- Эндпоинты: `kebab-case` (`/api/popular-queries`)
- JSON-поля: `camelCase`
- C# свойства: `PascalCase`
- DB-колонки: `snake_case` (через EF conventions)

## DTO

- Публичный API всегда через DTO, не Entity напрямую.
- Для списков — компактный DTO (ListItemDto).
- Для карточки — полный DTO (DetailDto).

## Slug

- Генерируется из названия: транслитерация + дефис.
- Уникален в рамках маршрута.
- Не содержит спецсимволов, только `a-z`, `0-9`, `-`.

## Фильтры

- Передаются через GET-параметры.
- URL обновляется при изменении фильтров.
- Состояние восстанавливается из URL.
- Не создают индексируемых страниц.

## Изображения

- Хранятся в S3 (MinIO).
- Обязателен `alt` для каждого фото.
- Оптимизация: WebP/AVIF при возможности.
- Lazy load для галерей.

## Кнопка «Посмотреть»

- `target="_blank"` + `rel="noopener noreferrer"`.
- Не показывать если `source_url` пустой.

## Git

- Коммиты на русском или английском, осмысленные.
- Одна задача = один PR/коммит.
- Не коммитить `.env`, `node_modules`, `bin/`, `obj/`.

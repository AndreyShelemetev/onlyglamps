# AGENTS.md — правила для AI-агентов (Codex / GPT / Claude Code)

## Общие правила

1. Работай маленькими шагами. Одна задача = один законченный результат.
2. Не делай несколько задач одновременно.
3. После каждого изменения проверяй: собирается ли проект, запускаются ли контейнеры.
4. Всегда обновляй TASKS.md после завершения задачи.

## Стек (не менять)

- Backend: ASP.NET Core 8 (C#)
- Frontend: Next.js 14 (React, TypeScript, Tailwind CSS)
- DB: PostgreSQL 16
- Storage: MinIO (S3)
- Reverse Proxy: Nginx
- Auth: Telegram Login
- Docker Compose для всех окружений

## Запреты

**Нельзя менять без отдельной задачи:**
- Маршруты (`docker-compose.yml`, `nginx/nginx.conf`)
- Slug-генерацию
- Canonical-логику
- Robots meta
- Sitemap
- Правила index/noindex
- Docker Compose структуру
- Reverse proxy конфиг

**Нельзя делать вообще:**
- SMS-коды и подтверждение телефона
- Email-регистрацию
- Индексируемые страницы из фильтров
- Несколько карточек одного объекта
- Менять модели данных без обновления миграций

## SEO-ограничения

- Индексируемые: `/`, `/{region}/`, `/{region}/{city}/`, `/{region}/{type}/`, `/{region}/{city}/{type}/`, `/{region}/{city}/{slug}-{id}/`
- Не индексируемые: всё с GET-параметрами, `/page/{n}/`, `/search/`, пустая выдача
- Canonical всегда = чистый URL без GET
- Title ≠ H1
- alt обязателен для фото

## Формат AI-задачи

```
## Задача: <название>

**Цель:** что нужно сделать
**Контекст:** зачем это нужно
**Файлы для изменения:** список файлов
**Файлы НЕ трогать:** список файлов
**Ожидаемый результат:** что должно получиться
**Критерии приёмки:**
- [ ] критерий 1
- [ ] критерий 2
**SEO-ограничения:** если применимо
**Docker-ограничения:** если применимо
```

## Definition of Done

Задача завершена, если:
- Код собирается
- Контейнеры запускаются (`docker compose up`)
- Миграции проходят
- Не сломаны URL-правила
- Не сломаны SEO-правила
- Нет индексируемых дублей
- Обработаны пустые состояния и ошибки
- Документация обновлена (если поведение изменилось)

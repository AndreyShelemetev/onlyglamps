# Входные данные

Пользователь может дать данные в свободном виде: ключевые слова из Wordstat, тему, регион, аудиторию, ссылки на похожие статьи, ссылки на страницы OnlyGlamps или короткое ТЗ.

Если данные даны не по шаблону, агент должен сам извлечь из них смысл и заполнить недостающие поля допущениями.

## Как агент должен работать с входными данными

1. Если пользователь дал только ключевые слова, агент должен:
- определить основной ключ;
- сгруппировать дополнительные ключи;
- предложить тему статьи;
- определить интент;
- предложить структуру.

2. Если пользователь дал тему и регион, но не дал ключи, агент должен:
- предупредить, что ключи не указаны;
- предложить примерный список ключевых фраз;
- написать статью под тему и регион.

3. Если пользователь дал ссылки на похожие статьи, агент должен:
- учитывать структуру и стиль;
- не копировать текст;
- сделать материал полезнее и глубже.

4. Если пользователь дал ссылки на страницы OnlyGlamps, агент должен:
- встроить их как внутренние ссылки;
- предложить естественные анкоры;
- указать, в каком разделе статьи их лучше поставить.

5. Если данных недостаточно, агент не должен останавливать работу.
Он должен сделать разумные допущения и явно написать их в начале результата.

# SEO-правила для статей OnlyGlamps

Каждая статья должна иметь:
- Title;
- Description;
- H1;
- Slug;
- Excerpt;
- Category;
- Tags;
- Structure;
- Content;
- HTML;
- Image idea;
- Internal links;
- Validation report.

Title:
- 55–70 символов;
- основной ключ ближе к началу;
- естественный и кликабельный.

Description:
- 140–170 символов;
- 1–2 ключевые фразы;
- без переспама;
- объясняет пользу статьи.

H1:
- до 7–10 слов;
- содержит основной ключ или его естественную вариацию.

Slug:
- латиницей;
- короткий;
- без дат, если дата не является частью темы;
- через дефисы.

Статья:
- 5000–8000 знаков без пробелов, если не указано иначе;
- минимум 5–7 H2;
- желательно 1 блок FAQ;
- обязательно внутренние ссылки на релевантные страницы OnlyGlamps;
- в конце мягкий CTA к выбору места отдыха.

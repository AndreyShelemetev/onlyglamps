# OnlyGlamps: стиль и тон

OnlyGlamps — сервис для поиска глэмпингов, гостевых домов, бань, баз отдыха и других мест для загородного отдыха в России.

Тон:
- дружелюбный, экспертный, спокойный;
- без канцелярита;
- без чрезмерного рекламного нажима;
- полезный для человека, который выбирает место отдыха;
- с акцентом на природу, комфорт, маршрут, впечатления, практическую пользу.

Писать на русском языке.

Не использовать:
- пустые фразы: "незабываемые эмоции", "уникальная атмосфера" без конкретики;
- переспам ключами;
- недостоверные факты;
- слишком длинные предложения;
- агрессивные CTA.
